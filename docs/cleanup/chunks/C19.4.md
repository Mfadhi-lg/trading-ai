Implementation:
- A small core contract converts each captured queue claim into a one-based invocation number. Generic/direct counts already include the current claim; browser compatibility rows retain their pre-increment count and normalize with +1. Browser native, host, bridge, content persistence, completion and renewal now use the same calculation. Stale/newer-token fences remain intact; invalid renewal counts raise OwnershipLost, preserving the prior failure contract.
- Browser transient retries explicitly allow **four invocations**, terminal on the fourth. Generic max_attempts retains its default three and existing backoff. Direct ratings retain their existing unbounded retry policy and 1800/3600/7200/14400/28800/57600-second schedule. Administrative cooldown, publisher block/unavailable, review and storage outcomes keep their existing distinct handling. Claims remain invocation accounting, not HTTP request counts: a claim may make multiple or zero requests, and crash/release consumes its existing recorded claim. No counters are reset or rewritten. Backoff clamps the exponent before calculation, avoiding excessive work for large restored counts.
- Read-only role health checks actual migration compatibility and required queue/policy/host columns plus supplied dependencies. Actual generic/direct role wrappers verify the document store; native browser verifies store and browser connectivity; the bridge verifies store and streams and observes dispatch/wait states. Missing schema/dependencies, failed observer, stopped/starting state, stale loop heartbeat or active work exceeding the observation threshold report unhealthy. Initial unhealthy checks refuse claim/request. Idle/ready/waiting/cooldown is healthy with current heartbeat and dependencies, without fabricated completed progress. Each claim starts its own timer so long idle time is not mistaken for a stall.
- Existing stderr lifecycle telemetry includes health; CLI stdout, bridge protocol versions/outputs, public facade signatures and return values remain compatible. Direct libraries without lifecycle retain their compatible behavior. Probe/observer failures cannot create queue retries. No Compose healthcheck or topology activation was introduced.
