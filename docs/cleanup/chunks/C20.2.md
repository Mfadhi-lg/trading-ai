All callers for a publisher must be coordinated before rollout; mixed legacy/shared execution is unsupported.

Every enabled GET/POST, manually validated redirect, rating landing/form request and recording stream holds a fenced shared permit. Short pacing waits renew the queue claim; longer host waits defer the owned job so unrelated hosts can proceed. A pre-dispatch administrative wait refunds this claim's attempt increment and fabricates no request/download/resolution attempt. Policy refusal skips safely and refunds an unspent attempt. After real dispatch, the attempt stays spent: generic records the observed redirect with the existing `rejected_http_status` schema value and explicit host-wait error code; rating retains completed original HTML steps/blobs plus an explicit deferred step. No false content success. Queue defers require the original owner/token/count and unexpired lease; stale workers cannot refund newer work.

Shared state preserves generic positive Retry-After override/defaults and rating 24-hour 401/403 / six-hour 429 defaults, honoring longer rating Retry-After. Transport/5xx failures feed the existing shared three-failure circuit; successes never clear future deadlines. Existing partition cooldowns are imported without changing their history. The shared normal-publisher policy remains a floor; no operator browser receipt is accepted by HTTP callers.

Physical I/O uses one Linux spawned child per hop. The child owns no DB/content store; the existing parent transport retains redirect/media/byte/recording-store ownership. A bounded pipe streams bytes and the cookie jar is carried between hops. Parent and child enforce one absolute monotonic request deadline; initial permit expiry extends 30 seconds beyond it, and active requests renew their reservation. Lost queue/permit ownership or timeout kills/joins the child **before** releasing capacity. Linux PDEATHSIG plus its registration-race check prevents a killed parent from leaving a request child running; an independent child deadline works without parent polling. Pre-dispatch queue loss releases capacity without incrementing transport-failure/circuit state. No DB write transaction spans I/O.

The existing direct-rating resolver's automatic browser fallback remains intact on the compatibility path.
