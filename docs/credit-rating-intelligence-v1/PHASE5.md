`credit_visual.py` adds an explicit original-PDF review binding: original hash, canonical hash, physical page, complete page-image hash, renderer/version, page dimensions, top-left source coordinates, crop hash and unchanged native locators. Admission re-renders the original and verifies the stored image/crop. No OCR or corrected native text is generated. The trusted review must pin the whole atom and record the reviewer, date, exact-source-review flag and `visual_pdf_inspection` method. Otherwise it remains queued or withheld. Damaged native support alone cannot admit an atom. Partial native extraction can use this path only with verified locators and the explicit visual review. Reviewers remain responsible for semantic entailment and crop-to-claim correspondence; hash checks cannot establish those facts.

New full-version generated claims record `native_text` and/or `table_cells` as their verification methods; visual corrections record `visual_pdf_inspection`. Original evidence retains its existing kind/origin. Historical records remain byte-compatible.

`credit_coverage.py` distinguishes missing candidates, pending source review, evidence failures and partial accepted coverage, while separately retaining parser-unresolved pages/regions. It never infers absence from AI omission. An optional absence-review input must explicitly bind the full catalog and every physical page, with reviewer/reason/exact-review confirmation.
