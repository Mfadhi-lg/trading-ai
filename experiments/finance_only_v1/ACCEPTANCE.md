# Acceptance decision — October 23, 2026

**ACCEPT the bounded research prototype for local review. DO NOT ACCEPT it as a
certified financial screening or production decision system.** The four-company
pilot is complete; no rollout or automatic membership action is authorized.

Delivered deterministic engine, canonical-facade snapshot adapter, four readable
reports, full JSON metrics/lineage, replay evidence and reproducible tests in
this isolated directory. No production connection, operational database writes,
acquisition-output changes, document-intelligence changes, inference calls,
Focus edits, GitHub push or Control Center/monitoring modifications were made.

## Reliable enough for V1 research, within stated limits

Supported for these four accepted standalone parses: stored revenue/PAT/EPS
history; matched annual/quarterly growth; positive-endpoint 3/5-year CAGR;
calculated operating/net margins; book-equity ROE; gross borrowings and basic
debt ratios; interest coverage; matched CFO/PAT; provider FCF; transparent
continuity/consistency and deterioration indicators. These are mechanically
reproducible and source-cell reconciled, conditional on source rounding,
same-month annual duration, corporate-action and restatement limitations.

Source ROCE and working-capital days are useful **provider indicators**, not
independently verified formulas. CCC arithmetic can be checked from rounded
components; TVS has a one-day FY2026 discrepancy, which is retained as a warning.
Implied capex is useful only under the source-FCF-definition qualification.

## Unsupported or not yet accepted

- Independent industrial ROCE, direct capex, verified net debt, independently
  calculated receivable/inventory/payable efficiency from underlying balances.
- Banking, NBFC, insurance, and unknown-sector industrial calculations.
- Verified audited annual durations, comprehensive restatement reconciliation,
  split/share-change comparability, subsidiary/group economics, publication-time
  historical features and historical mentor-decision reconstruction.
- Current production-wide completeness or a current independently verified Focus
  list; this pilot uses a historical snapshot and supplied Q1 reference.
- Certified scores or screening thresholds, automatic list changes, moat or
  Purple List decisions.

The original-HTML hash reconciliation gate, primary-filing reconciliation gate
and accounting-comparability gates remain **OPEN**. Thus Phase 4 achieves formula,
period-label, scope, lineage, missing-data and retained-cell verification, but
does **not** pass full independent-original financial certification. The pilot
stops here with those limitations recorded, rather than inventing missing data
or changing acquisition workflows to close them.
